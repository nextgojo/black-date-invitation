# Elegant Black Date Invitation

A black-and-gold, elegant date invitation in English, designed for iPhone and desktop.

## Test on Mac
Double-click `index.html` to open it in Safari or Chrome.

## Publish free with GitHub Pages
1. Create a **public** repository on GitHub, for example `elegant-date`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub to publish the page. Copy the URL shown in Settings → Pages and open it on your phone before sharing.

After accepting, the visitor can choose a date and time for the dinner. Tapping **Confirm our date** opens the share sheet when supported, or provides a copy/prompt fallback with the selected details.

The page is public to anyone with the link. No paid domain or hosting is required.
